Program Management

01

The Challenge

BrioForm — also known as The Athlete Standard — is a coach-led, 12-week athlete development program that combines physical workbooks, human coaching and digital tools to guide athletes through a structured plan.

Running that program across separate tools gets complicated fast: athletes, coaches, teams, cohorts, weekly activities, progress and communication all live in different places.

The goal was one centralized athlete management system that supports athletes, simplifies coaching operations and gives program leads full control — designed to support and complement human coaches, never to replace them.

02

What We Built

We developed complete online coaching software with three user roles, each with its own access and tools — from the athlete's weekly workflow to coach dashboard development for the people running the program.

Athletes

Follow the program
  • Access the structured 12-week development program
  • Complete weekly lessons, reflections and activities
  • Take part in weekly challenges and planning
  • Submit daily AM/PM check-ins
  • Upload photos of physical workbook pages
  • Track their own development and progress
  • Join live video sessions
  • Connect with their cohort in The Huddle

Coaches

Guide the athletes
  • Manage athlete cohorts and teams
  • Monitor team progress
  • Review athlete submissions and workbook uploads
  • Track action items and pending reviews
  • Message athletes directly
  • Run live coaching sessions

Admin / Program Lead

Run the program
  • Manage organizations, teams, cohorts and programs
  • Invite and manage coaches
  • Control program access and weekly unlocking
  • Manage billing and invoicing
  • Monitor platform analytics
  • Handle approvals and feedback collection

03

Key Features

From daily check-ins and the digital athlete workbook to athlete performance tracking and team progress tracking, every feature is built around the weekly rhythm of a 12-week training program.

01Authentication & User Management

  • Secure email and password authentication
  • Invite-based onboarding
  • Separate access and functionality for athletes, coaches and administrators

0212-Week Athlete Development Program

  • Structured weekly lessons
  • Reflections and activities
  • Weekly challenges
  • Planning and review activities
  • Week unlocking controlled by coaches and admins

03Daily Check-ins & Digital Workbook

  • Morning and evening AM/PM check-ins
  • Choice of paper-based or digital submissions
  • Photo uploads of physical workbook pages

04Live Coaching & Communication

  • Scheduled live video sessions
  • Built-in video call rooms
  • Direct messaging between users
  • The Huddle: a private, cohort-based social feed with posts, replies and likes

05Coach Dashboard

  • Team progress monitoring
  • Action items
  • Athlete submission reviews
  • Workbook upload management

06Admin Dashboard

  • Organization and team management
  • Cohort and program management
  • Billing and invoicing
  • Analytics built on real platform data
  • Approvals and feedback collection

07Notifications

  • In-app notification system
  • Instant alerts for submissions, messages and Huddle activity

08Android Application

  • Installable, native-like Android experience
  • Built as a Trusted Web Activity (TWA)

04

The Technology & Development

Full stack web development on a modern React web application, Supabase application development for data, authentication and storage, and Android app development that packages the progressive web application as a Trusted Web Activity.

Frontend

  • React 19
  • TanStack Start
  • TanStack Router
  • TanStack Query
  • Vite
  • Tailwind CSS v4
  • shadcn/ui
  • Radix UI

Backend & Database

  • Supabase
  • PostgreSQL
  • Supabase Authentication
  • Supabase Storage
  • Row Level Security (RLS)

Integrations & Services

  • Resend — email delivery
  • Jitsi Meet — live video sessions
  • Vercel — production hosting

Android Development

  • Trusted Web Activity (TWA)
  • Google's Bubblewrap
  • GitHub Actions — automated build & signing

How It Supports The Program

BrioForm brings the whole program into one place, so coaches can spend their time coaching.

01

Structure for athletes

Weekly lessons, check-ins and challenges unlock on schedule, giving athletes a clear path and a visible record of their progress.

02

Less admin for coaches

Submissions, workbook uploads and action items arrive in one coach dashboard, making team progress tracking simple.

03

Control for program leads

Organizations, cohorts, coaches, billing and analytics are managed from a single admin workspace.

04

Paper and digital, together

Athletes can keep using the physical workbook and upload photos, or work fully digitally — on the web or the Android app.
